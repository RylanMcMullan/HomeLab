# Incident History

One public-safe page per individual issue. Use the [incident template](../../reference/templates/incident-history.example.md) to keep the symptom, controlled tests, outcome, and remaining uncertainty easy to find. These pages are navigational summaries: current configuration belongs in host, service, and network records; detailed dated evidence stays in the linked topic history. Never paste raw logs, exports, addresses, credentials, or private inventories into an incident page.
